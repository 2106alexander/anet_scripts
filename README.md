1. Скрипт anet-install.sh устанавливает на сервер последнюю версию анет из официального репозитория ZeroTworu/anet и настраивает его для дальнейшей работы.
2. Скрипт anet-users.sh нужен для управления пользователями. Умеет добавлять, просматривать имеющихся и удалять пользователей. Генерирует файлы .toml, которые нужны пользовательским приложениям для подключения к серверу.
3. Скрипт anet-protocols.sh нужен для управления протоколами, включения/отключения оных, изменения портов и т.д.
4. Скрипт anet-uninstall.sh нужен для полного удаления anet  с сервера и очистки всех следов его присутствия.
5. Скрипт anet-install-panel.sh устанавливает anet и задействует панель управления anet-auth. Нужен для энтерпрайз развёртывания, но не для личных/семейных нужд.
